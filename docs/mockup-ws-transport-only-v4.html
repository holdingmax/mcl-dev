COMPARACION: MILESTONES AIRFREIGHT vs WS TRANSPORT Mismo /driver, misma cola, mismo PIN. Diferentes milestones segun el tipo de DO.
# Airfreight (DO-XXXXXXX) WS Transport (WS-DO-XXXXX)
1 Arrival at MCL Accept Order
2 Truck Loaded (+ foto) Arrived at Pickup (address)
3 Arrival at Airline Cargo Loaded (+ foto optional)
4 Gate Assigned Stop 1 (if extra stops) — dynamic
5 Unload Start Stop 2, 3... (dynamic per DO)
6 Unload End Delivered (+ foto, receiver, notes) → POD + billing
Key difference: Airfreight has 6 fixed milestones. WS Transport has 3 fixed (accept, pickup, loaded) + N dynamic stops + 1 final delivery. The milestones are built dynamically from the DO's route (extra stops).
Implementation: The DriverMobile.tsx component checks the DO prefix. If WS-DO-, it loads from ws_delivery_tracking and renders WS milestones with dynamic stops. If DO-, it uses the current delivery_tracking with the 6 fixed airfreight milestones. Same register, same queue, same PIN flow.
