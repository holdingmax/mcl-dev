1. Introduction

The Warehouse Services module provides a comprehensive platform for managing standalone warehouse operations at MinCurl Logistics. It covers the entire lifecycle of cargo handled at the warehouse—from initial service order creation through physical reception, screening, storage, and final delivery.

This module operates independently of the Sea Freight and Air Freight modules, serving clients who require warehouse services only (screening, storage, transport, repackaging, etc.).

General Workflow

SO Creation → Check-in → Physical Reception → Services → Delivery Order → POD

Each Service Order (SO) groups one or more services to be performed on cargo. Services include Screening (K9, X-Ray, Manual), Transport, Storage, In/Out handling, Repack, and DG Inspection.

Scope: This manual covers the Warehouse Services module only. For Air Freight or Sea Freight operations, refer to their respective documentation.

3. Dashboard

4. Creating a Service Order MCL

To create a new Service Order, click + New Order from the dashboard or navigate to the creation form.

Step 1: Select Client

Choose the client from the dropdown list of registered Warehouse Services clients.

Step 2: Order Information

FieldDescriptionRequired
PO (Purchase Order)Client's reference numberNo
AWB (Air Waybill)Airway bill number, if applicableNo
NotesAdditional instructions or commentsNo

Step 3: Select Services

Check the services required for this order:

Screening (select one)

  • K9 — Canine screening
  • X-Ray — X-Ray inspection
  • Manual — Manual physical inspection
Note: Only one screening type can be selected per Service Order.

Other Services (select multiple)

  • Transport — Includes pickup and/or delivery locations
  • Storage — Warehouse storage
  • In/Out — Warehouse handling (receiving/releasing)
  • Repack — Cargo repackaging
  • DG Inspection — Dangerous Goods inspection

Step 4: Cargo Details

FieldDescription
PiecesNumber of pieces
WeightTotal weight (kg or lbs)
TypeGeneral / DG / Perishable / Oversize
ModeLocal / Bonded

Step 5: Submit

Two submission options are available:

  • Create SO — Creates the order with status Requested
  • Create SO + Check-in — Creates the order and immediately checks in the cargo, setting status to Checked In
Screenshot: New Service Order form showing client selector, PO/AWB fields, service checkboxes (Screening, Transport, Storage, etc.), cargo details section, and the two submit buttons.

6. Physical Reception MCL

Physical reception is initiated from the SO Detail page by clicking the "Receive" button (available when status is Checked In).

Reception Lines

For each piece or group of pieces, enter the following:

FieldDescription
Packing TypePallet / Box / Carton / Crate / Drum / Bag / Other
QuantityNumber of pieces of this type
DimensionsL x W x H (inches or cm)
WeightWeight per piece or total
LocationWarehouse location code
DG FlagMark if Dangerous Goods
LB FlagMark if Lithium Battery
PhotosUpload photos of the cargo
RemarksFree-text notes

Totals

The system automatically calculates total pieces, CBM (cubic meters), and total weight from the reception lines.

Submitting

  • Save Draft — Saves progress without completing reception
  • Complete Reception — Finalizes the reception, generates a Warehouse Receipt (format: WS-XXXXXX), and automatically activates storage and in/out services if selected
Tip: After completing reception, the SO status advances to Received and labels become available for printing.
Screenshot: Physical Reception form with reception lines (packing type, qty, dimensions, weight, location), DG/LB flags, photo upload area, remarks field, and totals summary at the bottom.

7. Screening Services MCL

K9 Screening

For K9 (canine) screening:

  1. Upload the screening certificate (image or PDF) provided by the K9 handler
  2. Click Complete to mark the service as done

X-Ray / Manual / DG Inspection

For these screening types, the operator fills out a screening form:

FieldDescription
Inspector NameName of the person performing the inspection
Pieces InspectedNumber of pieces inspected
ResultPASS or FAIL
NotesDetailed observations
PhotosEvidence photos

Upon completion, the system automatically generates a PDF report stored in Firebase Storage. A "View Report" link appears in the SO Detail services panel.

CCSF Generation

If the Service Order has an associated AWB, a CCSF (Cargo Screening Security Form) can be generated:

  1. Enter the MCL Agent name
  2. Click Generate CCSF
  3. The system produces a CCSF certificate linked to the screening results
Note: CCSF generation is only available for orders that have an AWB number assigned.
Screenshot: X-Ray screening form showing inspector name, pieces inspected, PASS/FAIL result selector, notes field, photo upload, and the auto-generated PDF report link.

9. Warehouse Operations MCL

Locate Pieces (Barcode Workflow)

The Locate function allows warehouse staff to assign physical positions to individual pieces using barcode scanning:

  1. Scan piece barcode — Scan or type the piece barcode (format: WS-XXXXXX##, where ## is the 2-digit piece number)
  2. Choose location type — Select: Rack, Floor, or Container
  3. Scan rack position — Scan or enter the location code (format: ##A-E##, e.g., 03B-12)
  4. Confirm & Save — Review and confirm the assignment

A session counter tracks how many pieces have been located during the current session.

Screenshot: Locate Pieces screen at step 1 — barcode scanner input field with a scanned piece code, location type selector (Rack/Floor/Container), and session counter.

11. Labels & Printing

Labels can be printed from the SO Detail page or from the Warehouse Receipt print view by clicking "Print Labels".

Label Format (12 × 15 cm)

Each label contains:

ElementDescription
MCL LogoCompany logo at the top
Origin / DestinationCargo origin and destination
Date & TimeReception date and time
Warehouse NumberWarehouse Receipt number (WS-XXXXXX)
Shipper / ConsigneeShipping and receiving party names
SO NumberPrimary identifier — displayed prominently in large font
PO & AWBSecondary reference fields
Weight per PieceIndividual piece weight
BarcodeCODE128 barcode with format WS-XXXXXX##
Barcode Format: The barcode uses the Warehouse Receipt number followed by a 2-digit piece number (e.g., WS-00012301 for piece 1). It does not include the PO suffix.

12. Admin & Configuration MCL Admin

Administrative functions are accessed from the Admin Hub at /warehouse-services/admin. The hub presents navigation cards for each admin area.

Clients

Full CRUD (Create, Read, Update, Delete) management of Warehouse Services clients:

  • Company name and contact information
  • Billing information
  • Payment terms

Rates Admin

Define and manage rate schedules by service type. Rates are used to calculate billing charges when services are completed.

Billing Charges Admin

View and manage charges generated for each Service Order. Charges are calculated based on the rates configured and the services performed.

Invoices Admin

Create and manage invoices for billed services. Invoices can be generated from accumulated billing charges.

Screenshot: Admin Hub page showing navigation cards for Clients, Rates, Billing Charges, and Invoices, each with an icon and description.
