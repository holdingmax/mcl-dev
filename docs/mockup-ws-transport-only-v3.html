FLOW SUMMARY SO Create → DO (pickup+delivery+BUP/Loose) → POD (upload docs + date/time) → Charge + POD PDF → Invoice
Transport-Only Flow v3 — Changes from v2
Change Details
BUP/Loose in SO creation Transport type selected at SO level. If BUP, user enters number of BUPs.
BUP units prominent Big stat cards show BUP count. In DO form, BUP units shown large with optional ULD numbers input.
Custody optional Custody method and Seal # can be left empty (defaults to "None").
No estimated charge visible Removed from DO creation and all process steps. Only visible in Billing Charges.
Extra stop addresses When extra stops > 0, address fields appear for each stop. Shown in route display and PDFs.
Single upload zone One drag & drop zone for all documents (replaces separate slots). Multiple files, any type.
DO PDF Printable Delivery Order: route, driver, cargo lines, ULD numbers, signature lines.
POD Certificate PDF Generated at POD closure: delivery confirmation, full SO details, documents on file, route, driver info.
