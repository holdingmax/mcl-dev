Notas del prototipo:

  • Filtros: Buscar AWB, cliente, estado warehouse (D/R), vuelo asignado, fecha recepcion, destino
  • Seleccion: Checkbox para seleccionar 1 o mas AWBs. La barra azul muestra el conteo y acciones
  • Asignar a vuelo: Dropdown con vuelos existentes + busqueda + opcion "Crear vuelo nuevo"
  • Crear vuelo nuevo: Modal con campos basicos (numero, carrier, destino, fecha) + preview de AWBs seleccionadas
  • Quitar vuelo: Remueve el vuelo de las AWBs seleccionadas (quedan "Sin vuelo")
  • Bloqueo: AWBs en status B (Build-up) o superior no se pueden seleccionar ni mover — fila gris con candado
  • Origen: Indica si la AWB vino de un Booking o fue recibida "Sin booking"
  • Acceso: Desde el Dashboard Warehouse como boton "Vuelos"
